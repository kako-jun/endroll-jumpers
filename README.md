# endroll-jumpers

React + Vite + TypeScript で作成したジャンプアクションゲーム

Phaser 3 を使用したブラウザベースのジャンプアクションゲームです。エンドロールのように流れる障害物を避けながらジャンプし続けるゲームです。スマホでもPCでも快適にプレイできます。

## 操作方法

### PC

- スペースキー: ジャンプ

### スマホ・タブレット

- タップ: ジャンプ

## 技術スタック

- React 18
- Vite 6
- TypeScript 5
- Phaser 3
- Tailwind CSS 4
- Prettier + ESLint
- Husky + lint-staged

## 開発コマンド

```bash
# 依存関係のインストール
npm install

# 開発サーバーを起動
npm run dev

# プロダクションビルド
npm run build

# ビルドのプレビュー
npm run preview

# コードのフォーマット
npm run format

# Lintチェック
npm run lint
```
