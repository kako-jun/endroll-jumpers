# endroll-jumpers

React + Vite + TypeScript で作成したプラットフォームアクションゲーム

Phaser 3 を使用したブラウザベースのプラットフォームアクションゲームです。黒背景に白い線で描かれた地形を、画像から動的に認識して物理演算を適用します。2つのゲームモードを楽しめます：

- **プラットフォームモード**: 様々なプラットフォーム間を飛び移りながら自由に探索
- **エンドロールモード**: 縦長のエンドロール画像が流れる上を登っていくアクション

スマホでもPCでも快適にプレイできます。

## 特徴

- **高度な画像ベースの地形認識**:
  - 黒背景に明るい部分（白、灰色、文字など）を自動的に地形として検出
  - スタッフロール画像やブラウザのスクリーンショットも地形として認識可能
  - 明るさベースの判定により、様々な画像に対応

- **スーパーマリオ1風の物理演算**:
  - ボタンを押し続けることでジャンプの高さを調整可能
  - 空中での左右移動は地上より制御が効きにくい（慣性が強い）
  - 最大落下速度の制限
  - 摩擦による自然な減速

- **2つのゲームモード**:
  - プラットフォームモード: 複数の高さのプラットフォームを自由に探索
  - エンドロールモード: 縦長画像（2400px）が自動スクロールする上を登る

- **エンドロール演出**:
  - スタッフロール風のテキストが地形として機能
  - 自動スクロールでエンドロールが流れる
  - カメラがプレイヤーを追従

- **マルチデバイス対応**: PCはキーボード、スマホはタッチボタンで操作可能

## 操作方法

### メニュー画面

- クリック/タップでモード選択
- キーボード: 1キーでプラットフォーム、2キーでエンドロール

### ゲーム中（PC）

- 左右矢印キー: 左右移動
- スペースキー: ジャンプ
  - 短く押すと低いジャンプ
  - 押し続けると高いジャンプ（スーパーマリオ1と同じ）
- ESCキー: メニューに戻る

### ゲーム中（スマホ・タブレット）

- 画面右下のボタン:
  - ← : 左移動
  - → : 右移動
  - ↑ : ジャンプ（押し続けると高く跳ぶ）

## 開発コマンド

```bash
# 依存関係のインストール
npm install

# 開発サーバーを起動
npm run dev

# プロダクションビルド
npm run build

# ビルドのプレビュー
npm run preview

# コードのフォーマット
npm run format

# Lintチェック
npm run lint
```
