# Endroll Jumpers

画像から地形を自動認識するプラットフォームアクションゲーム。黒背景に白い線で描かれた地形を飛び移る。

## ゲームモード

- **プラットフォームモード**: 様々なプラットフォーム間を自由に探索
- **エンドロールモード**: 縦長のエンドロール画像が流れる上を登っていく

## 特徴

- 黒背景に明るい部分を自動的に地形として検出
- スーパーマリオ1風の物理演算（可変ジャンプ、空中制御、慣性）
- スタッフロール画像やスクリーンショットも地形として使用可能

## 操作方法

### PC

- 左右矢印キー: 移動
- スペースキー: ジャンプ（押し続けると高く跳ぶ）
- ESCキー: メニューに戻る

### スマホ・タブレット

画面右下のボタン:

- ← : 左移動
- → : 右移動
- ↑ : ジャンプ

## セットアップ

```bash
git clone https://github.com/kako-jun/endroll-jumpers.git
cd endroll-jumpers
npm install
npm run dev
```

http://localhost:5173 で開く
