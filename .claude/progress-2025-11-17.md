### 2. 地形認識の改善とスーパーマリオ1物理の実装

**目的**: 灰色や文字も認識できるようにし、ジャンプをスーパーマリオ1風に改善

**実装内容**:

#### 地形認識の改善

- **明るさベースの検出アルゴリズム**に変更
  - 従来: RGB > 200（白のみ）
  - 改善後: 平均明るさ ≥ 80（白、灰色、文字など）
- スタッフロール画像やスクリーンショットにも対応
- 様々な明るさの灰色プラットフォームを追加
  - `#FFFFFF` (白)
  - `#CCCCCC` (明るい灰色)
  - `#999999` (中程度の灰色)
  - `#888888` (やや暗い灰色)
  - `#AAAAAA` (テキスト風)

#### スーパーマリオ1風のジャンプ物理

- **可変ジャンプ高さ**:
  - ボタンを押し続けると高くジャンプ
  - ボタンを離すと即座に上昇を弱める
  - 最大300msまでジャンプブースト
- **空中制御の制限**:
  - 地上摩擦: 0.85（素早く減速）
  - 空中摩擦: 0.95（滑りやすい）
- **加速度ベースの移動**:
  - 慣性による自然な加速/減速
  - 最大移動速度: 200px/s
  - 加速度: 20px/s²

### 2. スーパーマリオ1風ジャンプ

```typescript
if (this.cursors.jump) {
  if (this.isOnGround && !this.isJumping) {
    // ジャンプ開始
    this.player.setVelocityY(this.jumpInitialVelocity)
    this.isJumping = true
    this.jumpStartTime = time
  } else if (this.isJumping) {
    // ボタン押し続け中のブースト
    const jumpDuration = time - this.jumpStartTime
    if (jumpDuration < this.maxJumpTime && body.velocity.y < 0) {
      this.player.setVelocityY(body.velocity.y + this.jumpHoldBoost)
    }
  }
} else {
  // ボタンを離したら上昇を弱める
  if (this.isJumping && body.velocity.y < 0) {
    this.player.setVelocityY(body.velocity.y * 0.6)
  }
  this.isJumping = false
}
```

## 開発メモ

### 技術的な課題と解決

1. **地形認識の精度**
   - 問題: 白いピクセルのみでは柔軟性が低い
   - 解決: 明るさベースの検出に変更（閾値80）

2. **ジャンプの気持ちよさ**
   - 問題: 一定高さのジャンプでは単調
   - 解決: ボタン押下時間で高さを調整可能に

3. **空中制御**
   - 問題: 空中で自由すぎると簡単すぎる
   - 解決: 摩擦係数を調整（地上0.85、空中0.95）

4. **エンドロールのスクロール**
   - 問題: 地形が動くと物理演算がずれる
   - 解決: 地形ボディもグラフィックスも同期して移動

### パフォーマンス考慮

- 地形検出は`preload()`で1回のみ実行
- ピクセルスキャンは訪問済みセットで重複を回避
- プラットフォームごとに物理ボディを作成（個別管理）
